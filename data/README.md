# Data

Raw data is **not committed** to the repo.

1. Download the [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) from Kaggle.
2. Unzip all CSV files into `data/raw/`.

Expected: 9 CSV files (orders, order items, payments, reviews, customers, sellers, products, geolocation, category name translation).
